# MEDIQ Frontend

This folder contains the React frontend for MEDIQ, a MERN-based healthcare appointment and management platform.

For the complete GitHub README with setup steps, features, API routes, environment variables, and project structure, see the root [README.md](../README.md).

## Run Frontend

```bash
npm install
npm start
```

Default frontend URL:

```text
http://localhost:3000
```

Optional `.env`:

```env
REACT_APP_API_URL=http://localhost:5000
```
